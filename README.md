# SaludTech - CRUD Pacientes y Vacunas

Mini sistema en PHP nativo + MySQL + Bootstrap 5.

## Instalación rápida
1. Importar `saludtech.sql` en phpMyAdmin.
2. Copiar `conexion.example.php` -> `conexion.php` y ajustar credenciales.
3. Poner la carpeta en `htdocs`.
4. Abrir: http://localhost/saludtech/pacientes_listar.php
